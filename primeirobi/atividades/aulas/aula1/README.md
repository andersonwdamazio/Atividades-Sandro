# 💻 Trabalho de JavaScript

## 📚 Sobre o projeto

Este projeto foi desenvolvido como parte das atividades da disciplina de programação, utilizando **JavaScript**.

O objetivo é praticar os principais conceitos da linguagem por meio da implementação das atividades propostas.

## 🛠️ Tecnologias utilizadas

* JavaScript
* HTML
* CSS
* Git
* GitHub

```text
JavaScript/

```

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone https://github.com/andersonwdamazio/JavaScript.git
```

2. Entre na pasta do projeto:

```bash
cd JavaScript
```

3. Abra o arquivo `index.html` no navegador.

## 📝 Atividades

O projeto contém as atividades desenvolvidas durante as aulas, com exercícios relacionados aos fundamentos de JavaScript.

Entre os conceitos trabalhados estão:

* Variáveis
* Operadores
* Condicionais
* Estruturas de repetição
* Funções
* Arrays
* Objetos
* Manipulação do DOM
